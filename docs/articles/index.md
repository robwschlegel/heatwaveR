# Articles

### Get Started

Core workflows for day-to-day package use.

- [Basic Detection and Visualisation of
  Events](https://robwschlegel.github.io/heatwaveR/articles/detection_and_visualisation.md):

  This vignette demonstrates the basic use of the heatwaveR package for
  the detection and visualisation of events.

- [Calculating and Visualising Event
  Categories](https://robwschlegel.github.io/heatwaveR/articles/event_categories.md):

  This vignette deomonstrates how to calculate and visualise the
  categories for events.

- [Calculating and Visualising
  Exceedances](https://robwschlegel.github.io/heatwaveR/articles/exceedance.md):

  This vignette demonstrates the use of the exceedence function.

### Advanced Workflows

Alternative thresholds, trend analysis, gridded data, and export
pipelines.

- [Alternative
  Thresholds](https://robwschlegel.github.io/heatwaveR/articles/complex_clims.md):

  This vignette walks the user through multiple different options for
  creating and applying thresholds outside of the default settings.

- [Trend and Breakpoint analyses in MHW
  metrics](https://robwschlegel.github.io/heatwaveR/articles/MHW_metric_trends.md):

  This vignette demonstrates the utility and limitation of running a
  trend and break point analyses in MHW metrics.

- [Downloading and Preparing NOAA OISST
  Data](https://robwschlegel.github.io/heatwaveR/articles/OISST_preparation.md):

  This vignette demonstrates how to download NOAA OISST data and prepare
  them for the detection of marine heatwaves.

- [Detecting Events in Gridded
  Data](https://robwschlegel.github.io/heatwaveR/articles/gridded_event_detection.md):

  This vignette demonstrates how to detect marine heatwaves (MHWs) in
  dataframes of gridded data in which each pixel is a separate time
  series.

- [Download, Prepare, and Analyse NOAA OISST Data: Alternative
  Methods](https://robwschlegel.github.io/heatwaveR/articles/Download_SST_v2.md):

  This vignette demonstrates an alternative method for downloading NOAA
  OISST data (using a python script) and preparing and detecting marine
  heatwaves.

- [Saving MHW Results to
  NetCDF](https://robwschlegel.github.io/heatwaveR/articles/MHW_to_nc.md):

  This vignette demonstrates how to save marine heatwaves (MHWs)
  detected from gridded data as a NetCDF file.

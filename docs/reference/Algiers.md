# Daily maximum (tX) and minimum (tN) air temperatures for Algiers, Algeria.

A dataset containing the daily maximum and minimum air temperatures (in
degrees Celsius) and date for Algiers, Algeria for the period 1961-01-01
to 2005-12-31.

## Usage

``` r
Algiers
```

## Format

A data frame with 16436 rows and 3 variables:

- t:

  date, as.Date() format

- tMax:

  daily max. temperature, in degrees Celsius

- tMin:

  daily min. temperature, in degrees Celsius

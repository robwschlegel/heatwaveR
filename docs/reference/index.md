# Package index

## Detect and Classify

Core tools for building climatologies and identifying events.

- [`ts2clm()`](https://robwschlegel.github.io/heatwaveR/reference/ts2clm.md)
  : Make a climatology from a daily time series.
- [`ts2clm3()`](https://robwschlegel.github.io/heatwaveR/reference/ts2clm3.md)
  : Make a climatology from a daily time series.
- [`detect_event()`](https://robwschlegel.github.io/heatwaveR/reference/detect_event.md)
  : Detect heatwaves and cold-spells.
- [`detect_event3()`](https://robwschlegel.github.io/heatwaveR/reference/detect_event3.md)
  : Detect heatwaves and cold-spells.
- [`exceedance()`](https://robwschlegel.github.io/heatwaveR/reference/exceedance.md)
  : Detect consecutive days in exceedance above or below of a given
  threshold.
- [`category()`](https://robwschlegel.github.io/heatwaveR/reference/category.md)
  : Calculate the categories of events.

## Summarise and Visualise

Event summaries and publication-ready plotting helpers.

- [`block_average()`](https://robwschlegel.github.io/heatwaveR/reference/block_average.md)
  : Calculate yearly means for event metrics.
- [`event_line()`](https://robwschlegel.github.io/heatwaveR/reference/event_line.md)
  : Create a line plot of heatwaves or cold-spells.
- [`lolli_plot()`](https://robwschlegel.github.io/heatwaveR/reference/lolli_plot.md)
  : Create a timeline of selected event metrics as 'lollipops'.
- [`geom_flame()`](https://robwschlegel.github.io/heatwaveR/reference/geom_flame.md)
  : Create 'flame' polygons.
- [`geom_lolli()`](https://robwschlegel.github.io/heatwaveR/reference/geom_lolli.md)
  : Visualise a timeline of several event metrics as 'lollipops'.

## Example Data

Observed temperature records used throughout the documentation.

- [`Algiers`](https://robwschlegel.github.io/heatwaveR/reference/Algiers.md)
  : Daily maximum (tX) and minimum (tN) air temperatures for Algiers,
  Algeria.
- [`sst_Med`](https://robwschlegel.github.io/heatwaveR/reference/sst_Med.md)
  : NOAA Optimally Interpolated (OI) v2.1 daily 1/4 degree SST for the
  Mediterranean region.
- [`sst_NW_Atl`](https://robwschlegel.github.io/heatwaveR/reference/sst_NW_Atl.md)
  : NOAA Optimally Interpolated (OI) v2.1 daily 1/4 degree SST for the
  NW Atlantic region.
- [`sst_WA`](https://robwschlegel.github.io/heatwaveR/reference/sst_WA.md)
  : NOAA Optimally Interpolated (OI) v2.1 daily 1/4 degree SST for the
  Western Australian region.

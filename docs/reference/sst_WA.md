# NOAA Optimally Interpolated (OI) v2.1 daily 1/4 degree SST for the Western Australian region.

A dataset containing the sea surface temperature (in degrees Celsius)
and date for the Western Australian region from 1982-01-01 to
2022-12-31.

## Usage

``` r
sst_WA
```

## Format

A dataframe with 14975 rows and 2 variables:

- t:

  date, as.Date() format

- temp:

  SST, in degrees Celsius

## Details

lon/lat: 112.625/-29.375

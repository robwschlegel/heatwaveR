# NOAA Optimally Interpolated (OI) v2.1 daily 1/4 degree SST for the NW Atlantic region.

A dataset containing the sea surface temperature (in degrees Celsius)
and date for the Northwest Atlantic region from 1982-01-01 to
2022-12-31.

## Usage

``` r
sst_NW_Atl
```

## Format

A dataframe with 14975 rows and 2 variables:

- t:

  date, as.Date() format

- temp:

  SST, in degrees Celsius
